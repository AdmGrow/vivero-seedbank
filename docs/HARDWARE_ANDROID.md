# Hardware — Android como base

Repo: vivero-seedbank.

## Que controla este repo

Lotes de semillas (`src/vivero_seedbank/`). No es una expendedora.
Android aca es planilla de campo / deposito, no kiosco de calle.

## Hardware minimo

- Tablet Android 8–10" indoor alcanza. No hace falta IP65.
- Camara para QR del lote.
- Opcional: impresora termica USB de etiquetas.
- NTP para fecha de lote / viabilidad.

Si mas adelante hay dispenser de sobres, ese I/O va en otro repo. Este solo anota lotes.
